# V1.1 Material Assistant

Depends on material posts branch (`feat/v1.1-material-posts` / PR #13). This branch does **not** merge that PR into `main`.

## Services

| Service | Role |
|---|---|
| Java `content` | Comments, assistant_tasks, search execution, feedback subscribe/resolve, giveaways, entitlements, notifications |
| Python `assistant-python` | Intent/parameter parsing only (`POST /v1/parse`). No DB. Auth: `X-Content-Internal-Token` |

When `content.assistant.python-url` is empty, Java uses `StubAssistantParser` (deterministic stand-in).

## Key APIs

- Comment with `@助手` / `@assistant` → normal comment + `assistant_tasks` + `AssistantTaskCreated` outbox
- `GET /api/assistant/tasks/{id}`
- `POST/DELETE /api/materials/{post}/feedback/{comment}/subscribe`
- `POST /api/materials/{post}/feedback/{comment}/resolve` body `{versionId, offsetMs?}`
- `POST/DELETE /api/posts/{post}/favorite`

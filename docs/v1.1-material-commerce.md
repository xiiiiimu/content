# v1.1 素材限量抢购

基线：`origin/main` @ PR #14 merge (`0426597`)。功能分支：`feat/v1.1-material-commerce`。

## 范围

1. **限量抢购**：活动配置、站内链接、Redis Lua 原子预扣、RocketMQ 异步落单、订单查询、PURCHASE 下载权益。
2. **退款 / 黑名单 / 抽奖资格**：中奖自动退款、买家申请与强制退款、商家拉黑、同账号素材串行决策、启用 `PURCHASE` 资格工具。

支付与退款均为模拟内部状态机。

## 核心表（V17）

| 表 | 作用 |
|---|---|
| `material_sale_campaigns` | 库存上限 / 已售 / 窗口；`open_guard` 保证同帖仅一个 OPEN |
| `material_purchase_requests` | 预占请求终态 PROCESSING→SUCCEEDED/REJECTED |
| `material_orders` | `UNIQUE(user_id, post_id)`；PAID / REFUNDED |
| `material_refund_requests` | 退款申请；成功 guard 每单一成功 |
| `merchant_blacklist` | 商家维度拉黑 |
| `account_material_decision_locks` | 购买落单与发奖串行 |
| `material_sale_consume_receipts` | 消费去重回执 |

## 路径

1. 买家抢购 → Lua 预扣 + 写请求 PROCESSING → 待发送 Stream → RocketMQ `PurchaseSettle`
2. 消费者 MySQL 条件更新库存、建单、发 PURCHASE 权益后 ACK
3. 中奖发奖前锁 `(account, post)`；已有 PAID 则 `GIVEAWAY_AUTO` 退款一次并通知一次，保留中奖权益

## 配置

- `content.sale.enabled`（默认随 media）
- `content.sale.sync-settle=true`：测试可同步落单
- `content.sale.topic` / `content.sale.consumer-enabled` / `content.sale.namesrv`

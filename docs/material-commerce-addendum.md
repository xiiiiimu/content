# 素材限量抢购追加 PRD

版本 1.0 · Content 创作者素材社区

在现有素材详情和抽奖流程上增加限量抢购、模拟退款和商家黑名单。素材作者是本期的销售主体。Java 负责订单、库存和权益，Python 助手继续解析抽奖指令，购买资格由 Java 根据订单事实核验。

## 1 作者配置与用户购买

作者为自己的素材帖配置模拟价格、库存、开始与结束时间。系统生成站内活动链接，素材页展示开抢时间、价格、库存状态和抢购按钮。首版限同素材一个进行中的活动，已开启活动的价格与库存上限冻结。

抢购请求返回请求 ID 和处理中状态。客户端查询最终结果，落库提交后显示模拟付款成功及下载入口。售罄、未开抢、已结束、已拥有、被限制和处理失败分别展示。

同一账号在同一素材帖最多一笔订单。版本升级、重开活动、退款、拉黑或解除拉黑都不会重置限购。客户端重试返回原请求或原订单状态。预占失败且从未落单的账号，条件满足时可重新申请。

## 2 退款与下载权益

已购买后获得同素材中奖权益时，系统自动模拟退款，将订单标为已退款，保留中奖下载权益，并发一次站内退款通知。已中奖并持有权益的用户购买时返回已拥有。

素材订单默认不可自助退款。买家可提交退款请求，经商家批准后完成模拟退款。强制退款通过具备权限的模拟运营操作完成。退款成功后撤销购买来源；同一账号的独立中奖权益继续有效。

退款完成时活动仍开放，归还该订单对应的已售名额一次。活动结束后保留退款账务记录。拒绝落单的预占统一释放，已关闭活动保持关闭。

## 3 商家黑名单

商家可以按账号拉黑或解除拉黑。买家主动或强制退款后，商家可以选择拉黑。拉黑禁止该账号购买该商家的任意素材，涵盖抢购和已有的其他购买入口。已有订单、下载权益和抽奖参与按原规则处理。解除拉黑后仍检查同素材历史订单。记录操作人、操作者所属商家、目标账号、原因和时间。

## 4 买过素材的资格口径

已模拟付款的购买订单计入资格。中奖导致的自动退款仍计入。用户主动退款或强制退款在成功后排除对应订单。退款申请中、拒绝或失败时，沿用当前有效订单状态。

只有中奖记录的账号在仅购买条件下不合格。账号另有满足活动范围的有效订单时仍可入池。每账号仅一个席位，继续复用已有资格树组合和去重逻辑。

按活动规则中的商家、素材范围和购买时间窗口查询，以订单的原始付款成功时间匹配窗口。在封池时用一致性读核验并持久化候选快照。封池后的退款影响后续场次，重试开奖复用快照。

订单及退款数据接通并通过集成测试后启用 PURCHASE。数据源不可用或规则范围无法解析时，封池明确失败且可重试，保持原条件和资格约束。

## 5 状态与原因

预占请求用 PROCESSING、SUCCEEDED、REJECTED 等状态表达异步结果，记录拒绝原因。订单只在最终落单时写入 PAID，退款成功后变为 REFUNDED。退款请求单独追踪申请、拒绝、成功，保留原订单和成交时价格。

退款原因分别记录 GIVEAWAY_AUTO、BUYER_REQUESTED、BUYER_FORCED。每笔订单至多产生一次成功退款。既有退款原因保持可审计，退款通知用订单 ID 和事件类型去重。

购买权益按素材帖发放，可用于该帖符合下载规则的 READY 版本。保留现有中奖权益的版本范围与可见性规则。中奖与购买冲突按同一素材帖判定；如果中奖仅授权指定版本，退款后用户继续下载该中奖版本。签发新链接时实时核验权益及素材可见性。

## 能力清单

| 能力 | 判定 | 依据 |
|---|---|---|
| Post 发布 / 幂等 / Outbox `PostPublished` | **已有** | `PublishService` / V2；编辑已发布帖不二次 `PostPublished`（CommunityFlowIT） |
| 下架 + 统一可见性 | **已有** | ADR-004；`VisibilityService` / `RelationshipService.offline` |
| Feed / 关注 / delivery_mode / mode_epoch | **已有** | M2/M3 pipeline |
| 评论 / 回复 / 通知 | **已有** | V13；`CommentCreated` → notifications |
| Like（赞成） | **已有** | `POST/DELETE /api/posts/{id}/likes`；`post_likes` |
| 反对（dislike） | **待补** | 无表无 API（全库无 downvote/dislike 业务） |
| 举报（report） | **待补** | 无受理模型；仅 IT/运维 “report” 字样 |
| Topic / 热点 | **已有（互动语义）** | `topic_event_ledger` 由 like/comment 驱动；**不是**作者素材 Tag |
| 作者 Tag / 标题描述检索 | **待补** | 发现需独立元数据 + MySQL 查询 |
| Media 原片/预览/封面 + 网关签名 | **已有（按帖单任务）** | `media_tasks` **UNIQUE(post_id)**；FFmpeg/ObjectStore；`/api/media/objects` |
| 素材多版本 / 默认版切换 | **待补** | 无 version 表；单帖单 media_task |
| 分享密码 / 下载授权 / 许可字段 | **待补** | 现仅可见性关注关系 |
| 评论 versionId + offsetMs + 采纳 | **待补** | `post_comments` 仅 parent_id |
| 帖子类型 TEXT vs MATERIAL | **待补** | `posts` 无 kind |
| 前端 Feed/热点/详情 | **部分** | Nuxt 页面有；无素材发现/版本/时间点/授权下载 |
| AI 点评（Python） | **第二批** | 本批不做 |

## 第一批复用点与变更边界

**复用**
- 统一 `posts` 主体、发布/下架/Feed/关注/评论通知/Like、Visibility、私有对象存储与媒体网关 HMAC、FFmpeg 转码组件。
- Topic 热点保持互动账本语义；素材 Tag 新建作者侧关联，不混入 `topic_event_ledger`。

**变更边界（本批）**
- Flyway V14：`post_kind`、素材档案/版本/Tag、评论时间点与采纳、dislike/report。
- 新 API：素材创建/版本上传、发现、分享解锁、预览/原片签名、采纳反馈；扩展评论字段。
- 新版就绪前不切换默认版；失败保留旧版；**不**重发 `PostPublished`、不改 `published_at` / `delivery_mode` / `delivery_epoch`。
- 反对/举报作为**通用帖子能力**落地，素材帖共用。

**不做（本批）**
- 画面/音频/转录检索；直传分片续传决策（先短对照再定）；Python AI 服务。

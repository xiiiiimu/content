# V1.1 第一批社区后端：已有接口 vs 缺口

基线：main `e27bf5f`；分支 `codex/v1.1-community-backend`。V2.1 + ADR 仍为架构契约；V1.1 为新增业务。

## 目标链路

A/B 注册登录 → B 关注 A → A 创建/编辑草稿并发布 → B 在 Feed 见帖并评论 → A 回复 → B 收通知并已读 → A 下架后 B 从通知无法读正文。

## 已有（复用）

| 能力 | 接口 / 机制 |
| --- | --- |
| HMAC 身份校验 | `FeedIdentityFilter` + `FeedTokens.Identity` |
| 关注 / 取关 | `PUT/DELETE /api/follows/{author}` |
| 发布 | `POST /api/posts/{id}/publish` |
| 下架 | `POST /api/posts/{id}/offline` |
| 关注 Feed | `GET /api/feed/following` |
| 读帖（可见性） | `GET /api/posts/{id}` |
| 点赞 | `PUT/DELETE /api/posts/{id}/likes` |
| 顶级评论创建 + 幂等 | `POST /api/posts/{id}/comments` |
| Outbox → MQ → Inbox | `PostPublished` / `FollowChanged` / `FeedModeChanged` / `PostOfflined` |

## 本批新增

| 能力 | 接口 |
| --- | --- |
| 注册 | `POST /api/auth/register` |
| 登录（签发兼容 Identity） | `POST /api/auth/login` |
| 创建草稿 | `POST /api/posts` |
| 编辑草稿/已发布（不重发首次发布事件） | `PATCH /api/posts/{id}` |
| 评论回复（parentId） | 扩展 `POST /api/posts/{id}/comments` |
| 通知列表 | `GET /api/notifications` |
| 标记已读 | `POST /api/notifications/{id}/read` |
| 通知跳转目标（再校验可见性） | `GET /api/notifications/{id}/target` |

明确不做：收藏、举报、标签发现、全文搜索、匿名、同城、Agent、用户自授 `TRENDGUARD_OPS`。

# ADR-004 下架可见性与分阶段验收

状态：已采纳，待实现与验收。基线：SDD V2.1 §8、T10。

## 判定与数据

下架写入 MySQL 权威状态，递增版本并在同事务记录 PostOfflined。使用 `UPDATE posts SET status='OFFLINE', version=version+1 WHERE id=? AND version=? AND status IN ('PUBLISHED','PROCESSING')`。媒体完成同时受期望帖子版本、状态和任务租约约束。应用读取在事务提交后发起的新请求，从主库读取权威状态与权限；缓存只提供候选或内容，旧缓存不能授权。批量过滤 Feed、榜单与话题。状态查询失败时返回可重试错误或拒绝访问。对于聚合榜，读取入口不得返回不可见帖子；历史互动对分数的影响按榜单窗口契约单独验收。

私有桶禁止永久公开链接。签发前查权威状态。已签发链接可能在有效期内继续访问，验收记录 TTL 和签发时间；若要求立即撤销，需由每次请求都鉴权的网关提供媒体。下架提交前已通过权威检查的在途响应另列边界。Outbox 失效用于加速，失效失败可重试。

## 验收顺序

| 阶段 | 用例 |
| --- | --- |
| M2 | 关注 Feed 已有最低限度的权威过滤，T03 验证过滤后可续扫。 |
| M4 | T10a 预热详情和关注 Feed 缓存，延迟失效消息，下架提交后两个入口都拒绝。 |
| M5 | T10b 热门 Feed、热点榜涉及的内容列表及话题页按权限过滤，旧 Redis 视图无法放行。 |
| M6 | T10c 验证私有桶、下架后拒发新签名、已签 URL 有效期边界及过期 Worker 无法复活帖子。 |
| M7 | 全入口回归，注入缓存回填竞态、MQ 延迟及权威读取失败。 |
